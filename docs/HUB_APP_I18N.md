# Hub App I18N

The Hub uses the shared localization provider for:

- language;
- country;
- currency;
- direction;
- timezone-aware formatting preparation.

Supported locale set matches user-app:

- FR
- EN
- ES
- PT
- DE
- IT
- AR
- RU
- ZH-CN

Arabic RTL selection is covered by unit and E2E tests. The Hub Playwright suite passed with 18/18 tests.
