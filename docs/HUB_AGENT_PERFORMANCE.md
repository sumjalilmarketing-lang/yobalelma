# Performance agents

Les tables `hub_agent_shifts`, `hub_agent_tasks`, `hub_agent_activity_logs` et `hub_agent_performance` portent les mesures par agent/hub/jour. La page `/hub/agents` agrège réception, inspection, mouvement, lots, erreurs, résolution, poids, durée, SLA et productivité.

Ces indicateurs sont assistifs. La métadonnée `disciplinary_automation=false` et l’interface rappellent qu’aucune décision disciplinaire automatique n’est autorisée.
