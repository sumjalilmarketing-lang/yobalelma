## Contrôles effectués

- compilation de production des cinq applications ;
- absence de débordement horizontal sur la largeur mobile contrôlée ;
- images avec alternative, boutons avec nom accessible et champs avec libellé ;
- comportement `prefers-reduced-motion`, contraste forcé et mode sombre défini dans les fondations ;
- navigation, cartes, formulaires, états, KPI, timeline et tableaux alignés sur les tokens communs.
