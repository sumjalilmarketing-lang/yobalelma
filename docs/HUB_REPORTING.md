# Reporting Hub

`/hub/reports` fournit les tendances opérationnelles et exécutives par hub. Les périodes cibles sont journalier, hebdomadaire, mensuel, trimestriel et annuel. Les exports associés couvrent inventaire, incidents, audit et performance.

Les calculs sont issus du read model autorisé ; aucune donnée d’un hub non accessible n’est incluse.
